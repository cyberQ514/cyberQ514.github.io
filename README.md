# 张美琪的个人主页

一个 HTML 文件的个人主页：终端风格、亮/暗双主题、页面上可以直接编辑。

- 线上地址：<https://cyberq514.github.io/>
- 修改方式：打开页面 → 右上角「编辑」→ 改完点「导出 HTML」→ 用导出的文件替换仓库里的 `index.html`

## 说明

- 单文件、无构建、无依赖，双击也能打开
- 编辑内容先保存在浏览器的 localStorage，**导出后才会写进文件**
- 主题选择同样保存在浏览器里
- 页面里的邮箱、GitHub、微信都是公开信息

## 目录

| 文件 | 说明 |
| --- | --- |
| `index.html` | 整个网站，样式和脚本都在里面 |
